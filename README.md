# report_work
# 📊 Ежедневный отчёт (Daily Report App)
Десктопное приложение для ведения ежедневных отчётов о работе. Позволяет фиксировать отработанные часы, задачи (тикеты), управлять шаблонами и отслеживать продуктивность с помощью встроенной аналитики.

## Основные возможности
- **Ведение отчётов:** добавление записей с указанием даты, времени начала/окончания и автоматическим расчётом часов (с учётом обеденного перерыва).
- **Блоки задач:** привязка тикетов (Jira, Redmine и т.д.) к шаблонам задач для быстрого заполнения.
- **Аналитика:** наглядные графики продуктивности (часы по дням, количество созданных и протестированных тикетов, распределение задач).
- **Помодоро:** встроенный таймер для работы по технике Помодоро.
- **Умные напоминания:** ежедневное напоминание, если вы забыли заполнить отчёт за текущий день.
- **Калькуляторы:** расчёт зарплаты (с учётом переработок и НДФЛ) и отпускных.
- **Импорт/Экспорт:** сохранение данных в JSON, импорт из `.txt` и экспорт в читаемый текстовый формат.
- **Кроссплатформенность:** адаптированный интерфейс для Windows и macOS (поддержка светлой и тёмной тем системы).

## Установка и запуск

### Вариант 1. Готовое приложение (без Python)
Скачайте готовую сборку из раздела [Releases]([https://github.com/](https://github.com/Aleksandriia/report_work/commits/releases)):
- Для **macOS**: `DailyReport.app`
- Для **Windows**: `DailyReport.exe`

### Вариант 2. Запуск из исходников
Убедитесь, что у вас установлен **Python 3.11** или выше.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Aleksandriia/report_work.git
   cd report_work
   ```

2. Установите зависимости:
    ```
   pip install matplotlib
    ```

4. Запустите приложение
    ```
   python main.py
    ```
(Для пользователей macOS рекомендуется запускать через Homebrew Python: ```/opt/homebrew/bin/python3.11 main.py```)

## Вариант 3. запуск файлов build
1. Для Windows просто запустите файл ```build.bat```

2. Для Mac сделайте файл ```build.sh``` исполняемым, введя в терминале:
    ```
   chmod +x build.sh
    ```
(Вы должны находиться в папке проекта)
    ```
    ./build.sh
    ```

*Обратите внимание, что при запуске приложения, оно какое-то время грузится. Экран загрузки будет добавлен позже.
